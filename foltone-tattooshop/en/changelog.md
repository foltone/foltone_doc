# Changelog

## v1.0.0

Initial release.

- NUI-based tattoo shop menu with modern UI
- Multi-framework support (ESX Legacy, QBCore, QBX)
- 700+ tattoos organized across 7 body zones
- Live tattoo preview on character
- Full keyboard navigation support
- Confirmation modal for buy/remove actions
- 6 pre-configured shop locations with map blips
- Camera rotation controls for character inspection
- Configurable interaction types (drawtext, ox_target, qb-target, marker)
- Customizable UI colors and menu style
